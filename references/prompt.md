# Appearance edit template

Use the built-in image-generation tool by default, after viewing every local target. Identify each reference's role.

Edit target: the first image is the validated high-fidelity 3D render. Keep its exact camera, full framing, plant population, species, root positions, heights/widths, crown silhouettes, trunk structure, hardscape topology, border width and empty paved landings. Additional crops/notes explain species and material appearance, never a different composition.

Task: improve only fine appearance inside permitted material interiors: leaf surface detail/translucency, bark, fine soil/mulch and concrete/steel material grain. Preserve leaf outline, alpha/opacity, size/shape, flower state and crown spacing. Match baseline lighting/exposure/shadows. Do not make plants larger/fuller, remove unusual specimens, change walls/caps/toes/returns, pave borders, populate landings, alter risers/stones or close fence/slat gaps.

Project cautions: insert relevant entries from planting-notes.json and exact ledger ID/species/traits/current condition. The schedule identifies plants; it does not authorize redesign.

Output one full-frame image at original dimensions, no labels. Preserve protected regions exactly. Save the exact prompt and reference paths/hashes. The result is only a candidate until recognition/protection/drift checks pass.
